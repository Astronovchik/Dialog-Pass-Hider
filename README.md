# AuthMe Password Mask

Клиентский Fabric-мод для Minecraft 1.21.11, который визуально заменяет
содержимое текстовых полей Dialog API с идентификатором `password` на звёздочки.

Настоящее значение поля не изменяется: AuthMeReloaded получает пароль в исходном
виде. Мод выполняет только визуальную маскировку и должен быть установлен у
каждого игрока.

Сборка:

```shell
./gradlew build
```

Готовый файл появляется в `build/libs/authme-password-mask-1.0.0.jar`.
